01 Is Kodza really free?

Yes. No account, no paywall, no “Pro” badge waiting in a corner. Copy what you like, ship it, keep the change.

02 Does it work in WordPress?

Paste the HTML in a Custom HTML block, the CSS in your theme and the script before the closing body tag. Every class starts with kodza-, so your theme will not even notice.

03 Do I need React?

No. Plain HTML, CSS and a pinch of vanilla JavaScript. If you insist, some components have a React tab.

04 What about accessibility?

Keyboard, focus, reduced motion and screen readers are checked before anything ships. Not perfect, never an afterthought.
