We shipped the redesign on a Friday at 4:40 pm.Yes, on purpose. Monday deploys only feel safer because nobody is looking. Nothing broke. The new header, the pricing page and thirty-one components went out in one deploy, and the error graph stayed flat all weekend.

The rollback plan fit in one command,git revert on the merge commit, then a push. The pipeline does the rest. and nobody had to run it. We had rehearsed it twice on staging, timed it, and written the number down: ninety seconds from the first alert to the old site.

The trick wasn't courage. It was a diff small enough to review in one sitting:If the review needs a meeting, the diff is too big. That's the whole rule. forty lines per pull request, one reviewer each, and a test that failed before it passed.
