02 · What's in the box

Everything it does. Nothing it fakes.

Six things done properly. The rest is on the changelog, with dates, not on a roadmap with vibes.

  • Previews per branch

    Every push gets its own address. Send the client a link, not a screenshot.

  • One-click rollbacks

    The last 50 deploys stay warm. Going back takes four seconds, not a meeting.

  • Forms, no backend

    Point the form at us. Spam filtered, replies in your inbox, nothing to host.

  • Logs you can read

    Plain text, with the request that broke it. Searchable for 30 days.

  • Cache in 40 cities

    Static files served close to the reader. Purged on deploy, never by hand.

  • Roles, not passwords

    Someone leaves the team, you remove one line. Nobody changes the Wi-Fi.
