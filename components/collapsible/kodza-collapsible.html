We started Kodza with one rule: every component should survive a copy and a paste. No build step, no framework, no “install these six packages first”.

So the CSS is scoped to its own classes, the JavaScript keeps to itself, and the HTML has no ids, so you can drop two of anything on the same page. It sounds boring. It is the point.

Then we added the fun part: motion that means something, a voice that does not take itself too seriously, and dark mode that is not an afterthought.

  • Spinner draws a tick when it is done
  • Progress rolls its digits
  • Skeleton takes its bones from the content
  • Alert folds away without a jump
  • Top Loading Bar slips off to the right
  • Empty State fans out its cards
  • Toast stacks like a deck
  • Tooltip glides between buttons
  • Cookie Consent makes Reject as easy as Accept
