Install

Paste the markup, the CSS and the script. That's the install. No package, no build step, no config file to babysit.

In WordPress

Leave the block empty and drop it anywhere in the post: it finds the headings of the article around it. Your theme's titles keep their look.

Behind a sticky header

The script measures your fixed header and stops each section just below it. Nobody lands on a title hiding under the logo.

Ids, handled

Headings without an id get one from their text. It goes away when the script stops, so the HTML you saved stays the HTML you wrote.
